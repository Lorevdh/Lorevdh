## Things I built

### [laravel-posts-project](https://github.com/Lorevdh/laravel-posts-project)

Laravel 13 + Tailwind 4. The fun part: a post belongs to exactly one author, and the app
*means it*. `PostPolicy` guards the door, and I wrote tests specifically to break it. UI and
tests are in Dutch, because the project is.

### [Cocktail-generator](https://github.com/Lorevdh/Cocktail-generator)

A tiny cocktail app in pure JavaScript — no dependencies, not even for the tests. Recipes
live in the browser and carry a `schemaVersion`, so a future change never quietly eats your
data.

### Game jams

Games built in game jams, one per weekend. Vanilla JS + canvas, no engine, no shortcuts.
`snake-inside-out` is the one I'd show first: instead of growing, you shrink, which turns a
reflex game into a thinking game.
